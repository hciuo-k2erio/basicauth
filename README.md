# jankenpo-python-cli

## Demonstração

Há um vídeo com uma partida completa.

## Execução

Primeiro instale o interpretador, seguindo as instruções do site oficial.

Depois, no terminal:

```
python index.py
```

## Testes

Instale a ferramenta de testes pelo gerenciador de pacotes:

`
pip install pytest
`

E rode:

`
pytest test.py
`

- Caso o comando nao responda, confira se a porta ja esta em uso.
